# Tixcash Community

Community governance and participation platform for the Tixcash ecosystem.

## Overview

This repository contains the tools and resources for Tixcash community governance, including:

- Community proposal submission and voting
- Service center management
- Staking reward distribution for community participants
- Regional community setup and onboarding guides

## Community Roles

- **Service Centers**: Local hubs responsible for onboarding new participants and providing support
- **Validators**: Community members participating in consensus and bookkeeping
- **Stakers**: Participants locking TXC for ecosystem rewards
